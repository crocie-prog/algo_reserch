## 1. Гипотеза

Фильтр направления по долгосрочному тренду улучшает S4-4h:

- SMA_200d = простая средняя close по **1200 рабочим барам 4h** (бары
  простоя не входят в окно, как во всех окнах проекта);
- лонг S4 разрешён только при close_t > SMA_t, шорт — только при
  close_t < SMA_t; при close_t = SMA_t и вне разрешённого направления —
  позиция 0;
- длина средней одна (200 дней), **не оптимизируется** и в сетку не входит.

Реализация — маска на позицию S4: pos_f(t) = pos_S4(t), если знак разрешён
на баре t, иначе 0. Решение по закрытию бара t, позиция действует с t+1;
SMA и S4 считаются по одному и тому же закрытию.

**Ловушки, записанные заранее:**
- прогрев: до готовности SMA (1200 рабочих баров) оба направления
  запрещены, позиция 0; у BTC/ETH/SOL прогрев заканчивается до первого
  квартала валидации (SOL: данные с 2021-10-15, SMA с ≈ 2022-05,
  валидация с 2023Q1), но он входит в train-окна;
- повторный вход: при возврате разрешения позиция S4 восстанавливается
  посреди тренда, без нового сигнала S4;
- whipsaw около SMA: частые пересечения дают лишние входы и выходы;
  гистерезиса нет (это был бы ещё один параметр).

## 2. Мотивация

- Фильтр направления был в программе исследований **до H3** (порядок
  H3 → H4 → H5, `docs/research_program.md` от 2026-10-04).
- Наблюдение H3b (лонг-сторона Sharpe 1.13, шорт −0.63, шорт отрицателен у
  всех трёх пар) мотивацию **усилило**: это результат просмотра 2024 г.,
  который теперь входит в train H4.

## 4. Критерии (EW-OOS по BTC/ETH/SOL за все фолды)

Критерии применяются **к каждой из двух попыток отдельно**: S4 + фильтр и
тайминг SMA_200d (контроль (б), §5).

EW-OOS — среднее чистых доходностей трёх пар на каждом 4h-баре в их периодах
валидации; кварталы без торговли — с нулевой доходностью. Пара торговала,
если у неё есть хотя бы одна сделка вне выборки.

| Вердикт | Условие |
| --- | --- |
| Значимо | Sharpe > 0, t по Lo ≥ 2, DSR ≥ 0.95, знак сохраняется при slippage 0.05%, торговали ≥ 2 из 3, все торговавшие > 0 |
| Кандидат | Sharpe > 0, t по Lo ≥ 1, знак сохраняется при slippage 0.05%, торговали ≥ 2 из 3, все торговавшие > 0 |
| Не подтверждена | иначе |

DSR: N сквозное = 28 (две попытки H4). Уровень 2 на частоте 4h: ряды H1–H3 и H4
коррелируются на общих барах (2022–2023), N_eff — по 95% следа; H3b (2024,
без общих баров с H1–H3) — отдельный кластер (+1), как в H3b.

**Шум:** 20 перестановок суток, та же процедура для каждой попытки
(S4 + фильтр с отбором; тайминг SMA_200d); доля перестановок, прошедших
критерий «кандидат». Правило прочтения: доля
≥ 0.25 → вердикт помечается «слабо» (вердикт не меняется, меняется
допустимый вывод).

## 5. Контроли

На тех же фолдах, парах, издержках и с тем же фильтром торгуемости.
(а) и (в) — `diagnostic`; **(б) — вторая попытка** (`attempt`), потому что
может стать кандидатом для test:

| Контроль | Определение |
| --- | --- |
| (а) S4-4h без фильтра | протокол H3/H3b на фолдах 2022–2024 |
| (б) тайминг SMA_200d | лонг при close > SMA, шорт при close < SMA, 0 на прогреве; без S4 и без отбора (параметров нет, отказа по train-DSR нет) |
| (в) buy & hold | лонг 1 с первого бара валидации пары до конца, funding по факту; вход облагается комиссией |

**Правило выбора кандидата для test (записано заранее):**
1. Кандидатом может быть только попытка, которая **сама** проходит условия
   «кандидата» §4 (Sharpe > 0, t ≥ 1, знак при slippage 0.05%, торговали
   ≥ 2 из 3, все торговавшие > 0).
2. Если проходят обе — на test идёт та, у которой выше EW-OOS Sharpe; при
   Sharpe S4 + фильтр ≤ Sharpe (б) идёт (б) (вклад S4 не установлен).
3. Если проходит одна — идёт она.
4. Если не проходит ни одна — test не открывается.

Выводится рядом: EW-OOS Sharpe, t, по годам, лонг/шорт для (а), (б), (в)
и разность Sharpe S4 + фильтр − (б) со стандартной ошибкой (Ledoit–Wolf
2008 с HAC) — для информации, не в критериях.

## 6. Вне критериев

- По годам 2022 / 2023 / 2024: EW-OOS Sharpe и число пар > 0.
- Лонг- и шорт-сторона отдельно (по знаку удерживаемой позиции).
- Доля времени, когда фильтр запрещает направление сигнала S4 (по парам
  и в EW), и доля времени в позиции до и после фильтра.
- Число сделок до и после фильтра; доля входов «посреди тренда» (по
  возврату разрешения).
- По парам, по кварталам, выбранные конфигурации; центр плато.
- Вторично — 10 пар H2: EW-OOS, знаковый тест по торговавшим, контроли.
- **Сравнение трёх стратегий по годам** — S4 + фильтр, тайминг SMA_200d,
  buy & hold: EW-OOS Sharpe, доходность и MDD за 2022, 2023, 2024 —
  чтобы видеть, где стратегия выигрывает за счёт защиты в медвежий период,
  а где проигрывает удержанию в бычий.

## 7. Ограничения

- **Весь train, включая 2024, просмотрен** (H1–H3b). Вердикт H4 на train —
  это **отбор, а не подтверждение**. Единственная независимая проверка —
  test 2025+.
- S4-4h выбрана по результатам H1, H3, H3b на тех же трёх парах.
- Мотивация фильтра усилена просмотром H3b (§2).
- 2022 — медвежий, 2023–2024 — бычьи годы: фильтр направления механически
  выигрывает в периоды с одним долгим трендом; в боковике около SMA —
  whipsaw. Поэтому по годам и контроль (б) выводятся обязательно.
- Три пары сильно коррелированы.

## 8. Попытки и журнал

- Попытки (`attempt`) — 2: (1) S4-4h + SMA_200d × ансамбль × expanding ×
  slippage 0; (2) тайминг SMA_200d × slippage 0; обе — EW-OOS BTC/ETH/SOL
  2022–2024. **N = 28.** Бюджет гипотез после H4 исчерпан.
- slippage 0.05% — `sensitivity`; контроли (а) и (в), центр плато, 10 пар
  H2 — `diagnostic`; train-записи — `train`; перестановки не пишутся.
