## 3. Стратегия и отбор

- **S4, сетка как на этапе 5:** n ∈ {24, 72}, m ∈ {2.5, 3.0, …, 7.0} — 20
  конфигураций; 1h; комиссия 0.1% на сторону, funding по факту, slippage 0.
- **Фильтры (как на этапе 5):** cost_to_band ≤ 0.2; trades_per_year ≥ 12 на
  train-окне. Конфигурации, прошедшие фильтры, — N_pass.
- **Правило выбора — одно: лучшая на IS** — конфигурация с наибольшим
  train-Sharpe среди N_pass, отдельно по паре и кварталу.
  Обоснование (этап 6, CPCV, агрегат BTC+ETH): лучшая на IS — медиана
  OOS-Sharpe путей 0.36, 5 из 5 путей > 0; процедура этапа 5 (ансамбль top-k
  с отказом по train-DSR) — 0.10, 3 из 5; PBO для лучшей на IS — 0.06.
  Центр плато в CPCV не оценивался, поэтому не выбран.
- **Правило отказа по train-DSR — снимается** (изменение относительно этапа 5).
  Обоснование: проверенная на этапе 6 процедура «лучшая на IS» работала без
  этого правила; на этапе 5 оно закрыло все кварталы S4 на ETH (train-DSR не
  выше 0.36) и вместе с ансамблем дало худший результат в CPCV. Защита от
  множественности остаётся на уровне вердикта: DSR с N сквозным (§5).
  Цена изменения: правило отказа и ансамбль на этапе 6 не разделены —
  вклад каждого по отдельности неизвестен.
- Торгуем, если N_pass ≥ 1 и квартал разрешён фильтром торгуемости.

## 5. Критерии (зарегистрированы заранее)

**Ряд оценки — EW-OOS по 10 парам:** на каждом баре среднее чистых
доходностей пар, находящихся в периоде валидации (до своего первого
квартала валидации пара не входит; закрытые фильтром торгуемости кварталы
входят с нулевой доходностью).

| Величина | Как считается |
| --- | --- |
| Sharpe | годовой, rf = 0 |
| t | по Lo (2002), HAC, q = ⌊T^{1/4}⌋ |
| DSR | N — сквозное (CLAUDE.md): 22 попытки H1 + попытки H2; N_eff — число собственных значений на 95% следа корреляции торговавших попыток на общих барах + 1 кластер на все попытки с нулевым рядом; V — дисперсия их Sharpe на бар |
| Знаковый тест | число пар из 10, у которых OOS-Sharpe (сшитые кварталы валидации) > 0; пара без единой сделки OOS считается неположительной |
| Чувствительность | тот же прогон при slippage 0.05% на сторону (не попытка) |

**Вердикт H2:**

| Вердикт | Условие |
| --- | --- |
| Подтверждена значимо | EW-OOS Sharpe > 0, t ≥ 2, DSR ≥ 0.95, не меньше 8 пар из 10 с OOS-Sharpe > 0, знак EW-OOS сохраняется при slippage 0.05% |
| Подтверждена (кандидат) | EW-OOS Sharpe > 0, t ≥ 1, не меньше 8 из 10 пар с OOS-Sharpe > 0, знак сохраняется при slippage 0.05% |
| Не подтверждена | иначе |

Порог «8 из 10»: односторонний биномиальный p ≈ 0.055 при независимых
парах; пары коррелированы, поэтому реальная сила знакового теста ниже —
порог взят 8, а не 7.

Условие t ≥ 1 для «кандидата»: знаковый тест на коррелированных парах в общем
режиме рынка слабее номинального, а «кандидат» ведёт к единственному
открытию test — поэтому нужен минимум значимости самого EW-OOS ряда.

Ожидание, записанное заранее: при OOS около 1.5–2 лет SE годового Sharpe
≈ 0.7–0.8; t ≥ 2 требует Sharpe порядка 1.5. «Подтверждена значимо»
маловероятна; реалистичный успех — «кандидат».

**Дополнительно выводится (не критерии):** таблица по парам (OOS-Sharpe,
сделки, доля кварталов, закрытых фильтром торгуемости), доля
закрытых кварталов в целом, данные train vs val по фолдам, базовая линия
шума (перестановки суток, 20 раз, та же процедура — диагностика);
EW-OOS Sharpe отдельно за 2022 и 2023 год и число пар с OOS-Sharpe > 0
в каждом году — чтобы видеть, не держится ли результат на одном режиме.

## 6. Попытки и журнал

- Попытка H2 — одна: S4 × «лучшая на IS» × expanding × slippage 0 × 1h,
  ряд EW-OOS 10 пар (`attempt`). Итого N = 23.
- slippage 0.05% — `sensitivity`; перестановки — не пишутся; train-записи
  каждой ранжированной конфигурации в фолде — `train`.

## 7. Что дальше

- **При успехе** («кандидат» или «значимо»): этап 7 — правила агрегации
  (пара → стратегия → МСП) на train, отдельной датированной записью; затем
  фиксация конвейера и **единственное** открытие test по порядку H1 §9.
- **При неудаче:** test не открывается и сохраняется; это фиксируется
  датированной записью; следующая гипотеза — с новой предрегистрацией, N
  продолжает расти.
