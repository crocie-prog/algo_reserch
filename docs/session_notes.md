### Находки отчёта качества

1. **Сверка агрегатов расходится только до 2022-01-01** (последнее
   расхождение 2021-12-29), после — ноль на всех парах и ТФ.
   В основном turnover (BTC 2020 — все часы), volume (BTC 2021 — 30% часов),
   реже close/high/low (BTC и ETH, февраль–апрель 2021; медиана 4e-5,
   максимум 1.6e-3 относительно). Похоже, старая история Bybit по разным ТФ
   собрана из разных источников.
2. **Простои отдаются плоскими барами с нулевым объёмом, а не пропусками**:
   2022-04-06 08:23–09:00 — на всех трёх парах. BTC 1m в 2020 — 28.5 тыс.
   минут без сделок (ранний неликвидный период).
3. **SOLUSDT funding**: 2022-11-10 — 2022-12-20 интервал 2 ч вместо 8 ч
   (период краха FTX); |ставка| до 2.5% за начисление. Привязка funding
   к барам по фактическим меткам это учитывает.
4. **Funding начинается раньше свечей**: ETH — с 2020-10-21 (свечи с
   2021-03-15), SOL — с 2021-06-29 (свечи с 2021-10-15). Контракты торговались
   до текущего launchTime, но API отдаёт свечи только с него.
5. Выбросы > 10σ: 1m — 0.04% баров, 1h — 16–24 на пару, 1d — 0. Не ошибки
   данных, а хвосты распределения; в отчёте для просмотра.
