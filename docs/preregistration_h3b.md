## 1. Гипотеза

S4 (Supertrend, 4h) с протоколом H3 без изменений даёт положительный
результат на периоде 2024-01-01 … 2024-12-31, который до этой
предрегистрации не просматривался (доходности за 2024 г. не считались).

## 3. Вселенная

## 4. Критерий (EW-OOS 2024 по трём целевым парам)

EW-OOS — среднее чистых доходностей BTC, ETH, SOL на каждом 4h-баре 2024 г.;
кварталы без торговли (отказ или ликвидность) — с нулевой доходностью.
Пара **торговала**, если в 2024 г. у неё есть хотя бы одна сделка.

| Вердикт | Условие |
| --- | --- |
| Подтверждена | EW-OOS Sharpe > 0, **и** знак сохраняется при slippage 0.05% на сторону, **и** торговали ≥ 2 из 3 пар, **и** среди торговавших все пары с OOS-Sharpe > 0 |
| Не подтверждена | иначе |

**Критерий — проверка на провал, а не доказательство:** один год и три
коррелированные пары. Даже без преимущества S4 вероятность пройти его
заметна: при независимых парах и симметричном шуме ≈ 1/8 – 1/4 (в
зависимости от числа торговавших), при сильной корреляции пар — выше.
t по Lo и DSR выводятся, но **в вердикт не входят**.

DSR (считается и выводится, в вердикт не входит): N сквозное = 26. Ряд H3b не пересекается по времени
с рядами H1–H3 (они кончаются 2023-12-31), поэтому корреляцию с ними
оценить нельзя; H3b считается отдельным кластером: N_eff = N_eff(H1–H3) + 1;
V — дисперсия Sharpe на 4h-бар по всем торговавшим попыткам (ряды H1/H2
агрегированы в 4h).

## 5. Выводится, не в критериях

- По кварталам 2024: EW-OOS Sharpe и Sharpe каждой целевой пары.
- **Лонг- и шорт-сторона отдельно**: вклад баров с позицией > 0 и < 0
  в доходность и Sharpe EW-OOS и по парам; доля времени в лонге и в шорте.
- По парам: OOS-Sharpe, сделки, доля кварталов без торговли (отдельно по
  train-DSR и по ликвидности), выбранные конфигурации по кварталам.
- Центр плато (diagnostic).
- Вторично — 10 пар H2: EW-OOS Sharpe, знаковый тест по торговавшим парам
  (число с OOS-Sharpe > 0 из торговавших), лонг/шорт.
- Базовая линия шума: 20 перестановок суток (та же процедура, только
  цели — BTC/ETH/SOL), доля перестановок, прошедших критерий §4.
  **Правило прочтения:** если эта доля ≥ 0.25, вердикт «подтверждена»
  помечается как **«слабое подтверждение»** — вердикт не меняется, меняется
  допустимый вывод (критерий плохо отличает стратегию от шума).

## 6. Ограничения

- **Выбор S4-4h сделан по результатам H1 и H3 на BTC/ETH/SOL** — по тем же
  трём парам, которые теперь целевые. Отбор «лучшей из увиденного» завышает
  ожидание; 2024 г. — первый период, где это не так.
- **2024 г. — бычий режим** (рост BTC и ETF-приток), благоприятный для
  трендовой стратегии; положительный результат может держаться на
  лонг-стороне одного режима — поэтому лонг/шорт и кварталы выводятся
  отдельно.
- Train для отбора в 2024 включает 2021–2023 — уже просмотренные данные.
- Три пары сильно коррелированы; эффективное число независимых
  наблюдений — около одного рынка за один год.
- **Правило отказа по train-DSR может закрыть 2024 г. на части пар.** При
  отказе на 2 из 3 целевых пар вердикт «не подтверждена» (торговали < 2) —
  это зарегистрированный исход, а не повод менять правила.

## 7. Попытки и журнал

- Попытка (`attempt`) — 1: S4-4h × ансамбль × expanding × slippage 0, ряд
  EW-OOS 2024 BTC/ETH/SOL. **N = 26.**
- slippage 0.05% — `sensitivity`; центр плато и вторичная вселенная —
  `diagnostic`; train-записи — `train`; перестановки не пишутся.
- Бюджет: H3b заменяет H5 (`docs/research_program.md`); после неё остаётся H4.
