## Внешние временные ряды

Автор использует 20+ внешних рядов (индексы, глобальные активы, макро) только
в прогнозной модели волатильности. В подходе A их нет: сигналы S1–S6 строятся
только по цене и объёму пары. До этапа 10 внешние ряды не подключать.

Когда дойдём (кандидаты: DXY, S&P 500, VIX, доминация BTC, funding, OI):

- выравнивание по времени ПУБЛИКАЦИИ, а не по отчётной дате (макро);
- данные с другим расписанием торгов (акции, индексы) — по последнему
  закрытому значению до момента решения; выходные и праздники — явно;
- пересмотры макроданных: только первая публикация (vintage), если доступна;
- каждый ряд — в `data/external/` с описанием источника и лага.

## Правила бэктеста

- Сигнал считается по закрытию бара t, позиция действует с бара t+1:
  `pnl = pos.shift(1) * ret - cost`.
- Позиция ∈ [−1, 1] (дробная допустима — ансамбль).
- Комиссия: **0.1% на сторону** от оборота:
  `cost = 0.001 * abs(pos.diff())`. Переворот лонг → шорт = два оборота.
- Безрисковая ставка: rf = 0. Одна и та же rf во всех сравнениях.
- Метрики стратегии (как табл. 5 статьи): годовая доходность, экспозиция
  (доля баров в позиции), Sharpe (годовой, аннуализация под ТФ, 365 дней),
  MDD, win rate, сделок в год.
- Санити-тесты движка обязательны (`tests/`):
  1. buy&hold совпадает с ценой;
  2. случайный сигнал ≈ −издержки;
  3. сигнал, сдвинутый на −1 бар, даёт подозрительно хороший результат —
     тест должен это ловить.

## Стратегии

| Код | Стратегия | Класс | Критичное |
| --- | --- | --- | --- |
| S1 | Z-score от MA | Контртренд | Порог выхода z_exit обязателен |
| S2 | Bollinger Bands | Контртренд | Проверить корреляцию с S1 |
| S3 | Donchian Channel | Тренд | Канал по барам до t−1 |
| S4 | Supertrend (ATR) | Тренд | ATR по Уайлдеру, рекурсивное состояние |
| S5 | Pivot S1/R1 | Диапазон | Уровни от закрытого предыдущего дня UTC |
| S6 | VWAP ± отклонение | Диапазон | Сессионный (якорь UTC 00:00) или скользящий — явно |

Интерфейс: `def signal(df: pd.DataFrame, **params) -> pd.Series` с позицией.
Каждый модуль сообщает число баров прогрева; на прогреве позиция = 0.

Пороги — только скользящим окном (mean ± k·std). Никаких квантилей и
нормировок по всей выборке.

## Подход A

- Сетка параметров → ранжирование по Sharpe на train-окне → топ-10 →
  позиция = среднее sign(pos) → если лучший Sharpe train ниже порога,
  стратегия в этом окне не торгует.
- Параллельно строить тепловые карты Sharpe по парам параметров.
  Робастность = плато, а не лучшая строка.
- Сравнивать ансамбль топ-10 с центром плато.
- Слой риск-менеджмента (SL/TP в ATR, max_hold) — только после базовой
  версии без него.

## Кросс-валидация

- Walk-forward: расширяющееся и скользящее окно, шаг — год.
- Purged K-fold с embargo — при перекрывающихся позициях.
- CPCV + PBO — на поздних этапах.
- Обязательная диагностика: scatter «Sharpe train vs Sharpe test» по фолдам.

## Статистика

- Sharpe: стандартная ошибка с учётом автокорреляции (Lo, 2002).
- ΔSharpe: Ledoit–Wolf (2008) с HAC и стационарный/блочный бутстрап.
  Не iid-бутстрап.
- Множественное тестирование: Deflated Sharpe Ratio, при необходимости SPA.
- Экономическая ценность: CE = r − (γ/2)σ², γ = 3, 5, 10.
- DM-тест — только для сравнения прогнозов волатильности.
